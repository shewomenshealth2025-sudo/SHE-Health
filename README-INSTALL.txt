HOW TO USE
1. Upload index.html, styles.css and script.js to your GitHub Pages repository.
2. Create an /assets folder in the same repository.
3. Add your existing website images using these filenames:
   - she-app-phone-visuals.png  ← your CURRENT top-right phone/app image
   - woman-navigating-health.jpg
   - she-helps-step-1.png
   - she-helps-step-2.png
   - she-helps-step-3.png
   - stormont.jpg
   - she-forum-panel.jpg
4. If your current images already have different filenames, either rename them or edit the src="assets/..." paths inside index.html.

IMPORTANT
The phone section is already coded to use your existing website phone image. I could see the live site has an image labelled “SHE app phone visuals”, but the public page view did not expose its exact file path, so I used a clean placeholder filename for you to match.
